# 信息稿类型与报送要求母表

资料来源：

- 《市场监管总局信息》四个子刊范例（2026年3月汇编，发省级市场监管部门和总局信息直报点）
- 《涉外信息范例》

说明：本母表先根据两份范例文件提炼“规则口径”。其中“数据信息”在范例汇编目录中列名，但正文只识别到分隔页，尚未形成完整规则，后续需从已采纳数据信息稿中补证。

## 一、刊物体系与报送对象

### 1. 市场监管总局信息（上报信息）

- **供稿主体**：总局司局、直属单位供稿
- **主要采编信息**：问题信息、正面信息、数据信息、涉外信息
- **报送/使用对象**：报中共中央办公厅、国务院办公厅
- **写作定位**：面向"两办"的上报信息，强调中央关切、问题价值、政策启示和可操作建议

### 2. 市场监管总局信息（基层反映）

- **供稿主体**：地方市场监管部门供稿
- **主要采编信息**：问题信息、涉外信息
- **报送/使用对象**：对内版头、落款与上报信息不同；上报中办、国办时无差别
- **写作定位**：地方/基层发现的问题和涉外动向，体例参照"上报信息"

### 3. 市场监管总局信息（内部参考）

- **供稿主体**：总局司局、直属单位和地方市场监管部门供稿
- **主要采编信息**：政策意见建议、风险隐患、新情况新问题新苗头、企业之声
- **报送/使用对象**：报总局领导
- **写作定位**："总局领导需要知道、需要总局领导知道"的内参性质信息

### 4. 市场监管总局信息（内部交流）

- **供稿主体**：以地方市场监管部门供稿为主
- **主要采编信息**：工作动态、地方要情、建言献策、司局反馈
- **报送/使用对象**：内部交流
- **写作定位**：偏工作交流和经验互鉴，可参考正面信息体例

## 二、四类上报信息母表

每种类型按"选题标准 / 基本结构 / 标题风格 / 对策建议写法 / 适用场景"五项拆解。生成稿件时按对应小节逐项套用，不要跨类型混用。

### 1. 问题信息 · 短篇

- **篇幅**：约 1000 字
- **选题标准**：紧扣中央领导关切、党中央国务院及"两办"重要部署、社会关注问题；问题要具体、重要、有风险外溢
- **基本结构**：帽段 + 具体问题（每个问题一个自然段）+ 对策建议（结尾一个自然段）
- **标题风格**：坚持问题导向。常用"主语+问题"、"主语+风险/困境/制约/隐患突出"、"主语+亟待加强/规范/纠正/调整/优化"；必要时用"警惕……"
- **对策建议写法**：

  > 对此，建议〔相关部委/部门〕：一是……；二是……。市场监管总局将……

  要点：先给"建议"（针对其他部门），再给"对策"（本部门下一步动作）。
- **适用场景**：单点问题明确、证据较集中、需快速上报

### 2. 问题信息 · 长篇

- **篇幅**：约 3000 字
- **选题标准**：重大、复杂、系统性问题；需要展开背景、问题成因和综合建议
- **基本结构**：通常分一级标题——一、背景/现状；二、存在问题；三、对策建议
- **标题风格**：标题需揭示问题要害，避免泛泛而谈
- **对策建议写法**：建议与问题逐项对应，体现"一把钥匙开一把锁"。可点名国家发展改革委、工业和信息化部、商务部、国家卫生健康委等相关部门，并写明市场监管总局职责内动作
- **适用场景**：复杂议题、跨部门治理、制度体系建设、长链条风险

### 3. 正面信息 · 部署类

- **篇幅**：约 600 字
- **选题标准**：已经审议、审签、即将正式发布/部署的重要政策、专项行动、文件、措施；报送时间应早于党务政务公开、新闻发布
- **基本结构**：帽段交代依据和即将部署事项 + 三四点重点部署
- **标题风格**：直陈"谁部署/会同谁部署什么工作"
- **对策建议写法**：一般不重建议，重点写"将/拟干什么"。不宜过早报送仍在征求意见或会签中的内容
- **适用场景**：近期拟开展专项行动、拟出台政策措施、拟制发重要文件

### 4. 正面信息 · 总结类

- **篇幅**：约 600 字
- **选题标准**：总局或相关部门已经推进并取得成效的工作，需与中央部署挂钩
- **基本结构**：帽段 + 三四点"措施/成效" + 结尾一句下一步或短板
- **标题风格**：突出"工作扎实推进""取得积极进展""持续提升"等
- **对策建议写法**：结尾可用一句话写主要梗阻、短板弱项或下一步思路；不展开对外建议
- **适用场景**：标准化、质量提升、监管改革、专项治理等工作成效

### 5. 数据信息（待补证）

> ⚠ 范例目录列有"数据信息"，但正文未识别到完整规则。下列要点为基于已有数据信息稿（科信司口径）的初步归纳，使用前应核对最新样本。

- **篇幅**：待补证
- **选题标准**：初步推测适用于趋势性数据、监测数据、清单统计、行业态势等
- **基本结构**：待从已采纳数据信息稿归纳
- **标题风格**：待补证
- **对策建议写法**：待补证
- **适用场景**：以数据支撑监管判断和趋势预判的主题

### 6. 涉外信息 · 国外动向类短篇

- **篇幅**：约 1000 字
- **选题标准**：单个国外动向必须是"近日"之事（几天内）；同类国外动向综合应为"近期"之事（一般一两个月内）
- **基本结构**：国外新动向/事件 + 主要做法/原因/影响 + 我方启示 + 下一步/建议
- **标题风格**：

  > 某国/某区域 + 加快/持续/频曝/通过…… + 值得关注 / 我需…… / 带来警示
- **对策建议写法**：

  > 下一步，市场监管总局将会同……等部门……。建议……等部门……

  先写本部门动作（对策），再点名相关部委（建议），聚焦预警、协同、标准输出、合规指导、风险应对。
- **适用场景**：国外监管政策、标准规则、技术法规、认证、贸易壁垒、质量安全事件

### 7. 涉外信息 · 国外动向类长篇

- **篇幅**：约 3000 字
- **选题标准**：国外规则、制度、监管趋势已经形成系统性影响，且与我国企业、产业、市场监管职责相关
- **基本结构**：国际趋势/规则变化 + 我国现状与问题 + 对策建议
- **标题风格**：常用"……渐成国际趋势"、"规则博弈加剧"、"……亟需……"
- **对策建议写法**：建议通常分条，兼顾顶层制度、部门协同、企业合规、标准/规则话语权
- **适用场景**：ESG 披露、碳足迹、技术法规、国际标准治理、海外合规规则

### 8. 涉外信息 · 国际经验类短篇

- **篇幅**：约 1000 字
- **选题标准**：重点围绕中央领导尤其总理关切；选取国外做法对我国当前治理问题有直接启示
- **基本结构**：国外经验/调查做法 + 对我国启示/建议
- **标题风格**：

  > 某国做法/调查……对我启示 / 建议借鉴美日欧经验
- **对策建议写法**：建议写得简洁，强调纳入监管视野、完善制度、借鉴机制
- **适用场景**：国外竞争监管、产品回收、房地产市场治理等可借鉴做法

### 9. 涉外信息 · 国际经验类长篇

- **篇幅**：约 3000 字
- **选题标准**：国外制度经验成熟，能支撑我国制度改革或政策制定
- **基本结构**：方案 A——一、国际经验；二、启示和建议。方案 B——一、国际通行规则；二、我国存在问题；三、对策建议
- **标题风格**："……国际经验及启示"、"亟需深化……构建……"
- **对策建议写法**：建议要制度化、体系化，常见写法为"推动专门立法"、"梳理现有规范"、"出台专项规范"、"对接国际规则、先行先试"
- **适用场景**：涉企行政执法、技术法规体系、标准化改革、统一大市场制度建设

## 三、共通报送要求

- **选题要精**：向中办、国办报送信息，应紧扣"上面"关切和社会关注，尤其围绕习近平总书记、李强总理等中央领导同志关心牵挂的问题，以及党中央、国务院和"两办"重要决策部署。
- **帽段要师出有名**：主题乍看一般、容易被轻视时，尽量在帽段点出中央领导指示批示、党中央国务院部署或重要政策文件，避免"师出无名"。
- **问题要实**：问题信息不能只作文字描述，要有例子、有数据；每个具体问题尽量列举 2 个以上例子，避免"孤证"。
- **结构要简**：短篇问题信息不要动辄设置"一、存在问题""二、对策建议"等标题，宜用帽段、自然段问题、结尾建议。
- **正面信息要控篇幅**：两办采用正面信息一般 400 字以内；总局上报稿可稍长，正文每一点约 100 字。
- **正面信息不宜举地方例子**：正面信息主要讲面上情况；问题信息反而需要地方例子、具体案例和数据。
- **部署类信息要抢时效**：应早于党务政务公开、新闻发布；适用于已进入正式发文/出台/行动前最后阶段的事项，不适合仍处征求意见、会签阶段的事项。
- **涉外信息重时效**：单个国外动向应为几天内的"近日"之事；同类动向综合一般应为一两个月内的"近期"之事。

## 四、标题公式库（初版）

按信息稿类型分组。生成标题时先定位类型小节，再套用对应公式，最后参照示例方向调整。

### 问题信息

- `主语 + 存在漏洞/风险/困境/制约/隐患突出`
  示例："……存在……风险"、"……面临……困境"
- `主语 + 亟待加强/规范/纠正/调整/优化`
  示例："……亟待规范"、"……有待优化"
- `警惕 + 风险/苗头/趋势`
  示例："警惕……风险"

### 正面信息 · 部署类

- `市场监管总局/多部门 + 部署/印发/启动 + 工作`
  示例："市场监管总局等部门部署加强……"

### 正面信息 · 总结类

- `主题 + 取得积极进展/扎实推进/持续提升`
  示例："新能源汽车标准化工作扎实推进"

### 涉外信息 · 国外动向类短篇

- `国别/区域 + 加快/持续/频曝/出台 + 事项 + 值得关注`
  示例："欧盟加快推进……动向值得关注"
- `国外事件 + 我需/我应 + 引以为戒/高度关注/积极应对`
  示例："日本……频曝……我需引以为戒……"

### 涉外信息 · 国外动向类长篇

- `国际趋势 + 我国体系/企业/监管 + 有待改进/亟需应对`
  示例："……渐成国际趋势 我国……有待改进"

### 涉外信息 · 国际经验类

- `国外做法 + 对我启示/建议借鉴`
  示例："英国……对我启示"、"建议借鉴美日欧经验"

### 涉外信息 · 制度改革长篇

- `推进国家战略 + 亟需 + 深化改革/构建体系`
  示例："推进全国统一大市场建设 亟需深化……改革构建……"

## 五、对策建议写法母式

### 1. 问题信息

基本句式：

> 对此，建议〔相关部委/部门〕：一是……；二是……。市场监管总局将……

写法要点：

- 建议对象是“其他对象”，不能只写本部门想法。
- 同时列明“对策”，即市场监管总局或本单位下一步计划开展的工作。
- 对策建议要与前文问题逐项对应，避免泛化。
- 可点明国家发展改革委、工业和信息化部、商务部、文化和旅游部、国家卫生健康委、公安、交通运输、生态环境等，具体以后续主题和司局职责匹配。

### 2. 正面信息

基本句式：

> 目前，……但仍存在……等短板。下一步，市场监管总局将……

写法要点：

- 正面信息不是建议稿，重点在“工作进展”和“下一步”。
- 总结类可在结尾交代短板，但篇幅要短。
- 部署类重点写即将开展的重点任务，少写组织领导、宣传引导等保障性内容。

### 3. 涉外信息

基本句式：

> 下一步，市场监管总局将会同……等部门……。建议……等部门……

写法要点：

- 先写市场监管总局职责内动作，体现“对策”。
- 再点名相关部门提出“建议”，体现跨部门协同。
- 国外动向类建议常围绕风险预警、技术性贸易壁垒研判、标准化合作、企业合规、信息共享。
- 国际经验类建议常围绕制度建设、立法修法、机制完善、试点先行、数据平台建设。

## 六、后续样本分析要补证的问题

- **数据信息的完整体例**：从科信司信息稿中的"数据信息稿 0511/0512"、"0516-附件 4：数据信息"等材料补。
- **创新司/科信司口径差异**：从总局官网职责、司局近期政策/会议/通知，以及已采纳稿件落点补。
- **基层反映与上报信息的实质差异**：对比已采纳《基层反映》样本和《上报信息》样本。
- **涉外信息中"国外动向类"和"国际经验类"的边界**：从涉外信息范例及采纳专报范文中欧美、印度、非洲、金砖、AI 规则等样本补。
- **对策建议点名单位的规律**：从所有采纳稿件结尾建议段，提取"建议 X 部门"与主题映射。
- **大标题可采纳句式**：从已采纳 PDF/DOCX 标题全集，对照类型建立标题公式库。
