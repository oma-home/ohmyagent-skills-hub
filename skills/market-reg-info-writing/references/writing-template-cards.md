# 信息稿写作模板卡

资料基础：

- 《市场监管总局信息》四个子刊范例
- 《涉外信息范例》
- 已采纳上报信息、基层反映样本
- 科信司 AI 标准/智慧监管数据信息稿、问题信息稿、涉外信息稿

## 卡片索引

按信息稿类型定位卡片，按需读取对应章节即可，无需通读全文：

- **问题信息 · 短篇**（约 1000 字）→ 卡片 1
- **问题信息 · 长篇**（约 3000 字）→ 卡片 2
- **涉外信息 · 国外动向类短篇** → 卡片 3
- **涉外信息 · 国外动向类长篇** → 卡片 4
- **涉外信息 · 国际经验类短篇** → 卡片 5
- **涉外信息 · 国际经验类长篇** → 卡片 6
- **数据信息** → 卡片 7
- **正面信息 · 部署类** → 卡片 8
- **正面信息 · 总结类 / 案例示范类** → 卡片 9
- **基层反映** → 卡片 10

如果尚未确定类型，先看末尾的"类型选择速查"。

每张卡片固定包含以下小节，按需逐项套用：**适用场景** / **标题公式** / **正文骨架** / **小标题句式**（部分长篇卡有） / **语言风格** / **对策建议模板** / **常见误区**。

## 卡片1：短篇问题信息

**适用场景**

- 单一问题清楚，风险具体，能用案例或数据支撑。
- 需要快速向“两办”反映市场监管领域苗头性、倾向性、风险性问题。
- 篇幅约1000字。

**标题公式**

- `主语 + 存在/面临 + 风险/困境/制约/隐患`
- `主语 + 亟待加强/规范/调整/优化`
- `警惕 + 某类风险/苗头/趋势`

**正文骨架**

1. 帽段：用1段交代政策背景、问题价值、风险后果，必要时点出中央部署或领导关切，做到“师出有名”。
2. 问题1：一句判断 + 例子/数据 + 影响。
3. 问题2：一句判断 + 例子/数据 + 影响。
4. 问题3：一句判断 + 例子/数据 + 影响。
5. 建议段：点名相关部门，提出2-4条对应建议，同时写明市场监管部门下一步动作。

**语言风格**

- 直奔问题，少铺陈。
- 每段开头用判断句压住观点。
- 例证要实，避免“有的地方”“部分企业”后面没有数据或案例。

**对策建议模板**

> 对此，建议〔相关部委〕等部门：一是……；二是……；三是……。市场监管总局将……

**常见误区**

- 短篇稿不宜再设“一、存在问题”“二、对策建议”等大标题。
- 不能只有概念判断，没有例子、数据或具体场景。
- 建议不能泛泛写“加强监管、完善机制”，要对应前文问题。

## 卡片2：长篇问题信息

**适用场景**

- 议题复杂，涉及制度体系、跨部门治理、产业链安全、国际规则冲击。
- 需要展开背景、现状、问题、原因和系统性建议。
- 篇幅约3000字。

**标题公式**

- `某趋势/新动向 + 对我国某领域提出新要求/带来新挑战`
- `某领域存在问题 + 亟需系统谋划/加快迭代/强化应对`
- `国际/国内新变化 + 及我国某治理体系迭代之策`

**正文骨架**

1. 帽段：概括新形势、新趋势、新挑战，点明对市场监管职责的影响。
2. 一、现状/动向：通常分3个二级标题，每个标题采用“由A向B转变”“从A转向B”的趋势判断。
3. 二、问题/挑战：从监管对象、监管工具、监管能力、制度机制等角度拆解。
4. 三、对策建议：每条建议与前文问题对应，强调制度、平台、标准、机制、能力建设。

**小标题句式**

- `治理方式由“……”向“……”延伸`
- `治理工具由“……”向“……”下沉`
- `治理范围由“……”向“……”升级`
- `监管难点从“……”转向“……”`

**语言风格**

- 更像咨政建议，判断要前瞻，逻辑要层层递进。
- 多用“趋势判断 + 国内影响 + 监管启示”的三段式。
- 可以引用国外机构、政策、标准、报告，但必须回扣我国市场监管场景。

**对策建议模板**

> 一是构建……体系，闭环布局……。二是建设……平台，强化……能力。三是推进……体系建设，打造……生态。

**常见误区**

- 不要只写国际动态，必须落到我国市场监管的制度、技术、平台或能力短板。
- 不要把建议写成一般工作部署，要体现“为什么由市场监管部门牵头或参与”。

## 卡片3：涉外信息：国外动向类短篇

**适用场景**

- 国外近期出台法规、标准、认证、贸易壁垒、监管措施或发生质量安全事件。
- 单一国外动向应是几天内“近日”之事；同类动向综合一般是一两个月内“近期”之事。
- 篇幅约1000字。

**标题公式**

- `某国/区域 + 加快/持续/频曝/出台 + 某规则/事件 + 值得关注`
- `某国/区域 + 某行为/规则 + 我需引以为戒/高度关注/积极应对`
- `某规则/机制进入关键阶段 + 或对我产业造成冲击`

**正文骨架**

1. 帽段：交代国外最新事件、数据、政策动作和对我影响，结尾用“亟需高度重视并予以应对”。
2. 动向/影响1：国外规则怎么变，对我有什么直接影响。
3. 动向/影响2：执行机制、认证、核查、默认值、准入条件等如何构成壁垒。
4. 动向/影响3：产业链、供应链、企业出海或规则话语权风险。
5. 建议段：点名相关部委，提出维权、研判、预警、合规、标准/认证能力建设等建议。

**语言风格**

- 时效强，第一段必须有新近事实。
- 结论鲜明，多用“严重威胁”“削弱竞争力”“构成系统性挑战”等政策判断。
- 数据密度较高，常用“截至某日”“增长至”“覆盖多少类产品”等。

**对策建议模板**

> 对此，建议商务部、海关总署、市场监管总局等部门：一是运用WTO机制积极维权……；二是加强法规和市场准入政策研判……；三是加快检测认证/标准能力建设……

**常见误区**

- 不要把涉外稿写成国际新闻摘要，必须说明“对我影响”。
- 国外动向类短篇不宜写得太散，最好围绕一个规则、一个国家或一个事件展开。

## 卡片4：涉外信息：国外动向类长篇

**适用场景**

- 国外规则变化已形成制度型壁垒或系统性冲击。
- 涉及产业链、供应链、国际标准、认证认可、碳规则、ESG、人权劳工、技术法规等。
- 篇幅约3000字。

**标题公式**

- `某国际规则/机制 + 进入关键阶段 + 或对我产业造成剧烈冲击`
- `某规则/议题 + 已上升为战略议题 + 亟须系统谋划、主动应对`
- `欧美/印度/欧盟 + 借某规则构筑新型壁垒 + 我应高度关注并系统应对`

**正文骨架**

1. 帽段：国外规则最新节点 + 我国受影响规模数据 + 规则冲击的总判断。
2. 一、主要挑战：通常3-4条，按“规则范围、成本压力、合规壁垒、产业转移/供应链风险”展开。
3. 二、对策建议：按“跨部门机制、企业赋能、规则互认、国际谈判、产业布局”展开。
4. 落款/报送：可出现联合报送单位。

**小标题句式**

- `管控范围“穿透延伸”，……压力骤然加大`
- `证书价格“挂钩市场”，……遭受冲击`
- `核查体系“资质垄断”，……受制于外部壁垒`
- `规则设计“诱导转移”，……面临重构风险`

**语言风格**

- 战略性更强，强调“制度型壁垒”“规则主导权”“产业链安全”。
- 常采用引号凝练关键词，增强标题力度。
- 建议对象多部门并列，体现综合施策。

**对策建议模板**

> 国家发展改革委、商务部、生态环境部、工业和信息化部、海关总署、市场监管总局、外交部等部门协同发力、综合施策。一是……；二是……；三是……；四是……

**常见误区**

- 不要只写市场监管单部门工作，长篇涉外动向往往需要国家层面、跨部门统筹。
- 对策建议要能覆盖前文每一类挑战。

## 卡片5：涉外信息：国际经验类短篇

**适用场景**

- 国外某项监管做法、调查机制、制度安排对我国有直接启示。
- 适合围绕中央领导关切或国内正在推进的治理任务借鉴经验。
- 篇幅约1000字。

**标题公式**

- `某国 + 某监管做法/调查 + 对我启示`
- `建议借鉴美日欧经验 + 完善我国某机制`
- `某国某制度安排 + 值得借鉴`

**正文骨架**

1. 国外背景：为什么该国开展此项监管或制度改革。
2. 主要做法：列出3-5个国外做法。
3. 对我启示：用1段或2-3点写可借鉴方向。

**语言风格**

- 语气比“国外动向类”温和，少用冲击、风险、壁垒，更多用“启示”“借鉴”“纳入监管视野”。
- 重点不是批判国外，而是提炼可为我所用的制度工具。

**对策建议模板**

> 建议将……纳入监管视野，完善……机制，探索……制度安排。

**常见误区**

- 不要罗列国外材料，必须转化为我国监管启示。
- 经验类不是“宣传国外先进经验”，而是服务我国政策制定。

## 卡片6：涉外信息：国际经验类长篇

**适用场景**

- 国外制度经验较成熟，可为我国重大制度建设、法律法规、标准体系改革提供借鉴。
- 适合涉企行政执法、技术法规体系、标准化改革、统一大市场等主题。
- 篇幅约3000字。

**标题公式**

- `某制度/领域 + 国际经验及启示`
- `推进某国家战略 + 亟需深化某改革构建某体系`
- `借鉴国际通行规则 + 完善我国某制度体系`

**正文骨架**

1. 帽段：中央部署/国家战略 + 我国现实堵点 + 借鉴国际经验的必要性。
2. 一、国际经验/国际通行规则：按欧盟、美国、俄罗斯/日本/新加坡等分组，每组写制度逻辑和数据事实。
3. 二、我国存在问题：立法缺位、界限不清、机制不顺、国际规则不接轨等。
4. 三、对策建议：专门立法、摸清底数、出台规范、建设数据库、开展先行先试。

**小标题句式**

- `欧盟……实现“法规—标准—监督”全链条监管`
- `美国……制度完备，专业机构负责数据管理`
- `俄罗斯通过……改革确立……地位`
- `技术法规相关立法缺位，技术规则体系不完整`

**语言风格**

- 制度分析味道更重，常用定义、协议、法规、数据库、统计数据。
- 论述逻辑是“国际规则成熟 → 我国问题突出 → 制度建设建议”。

**对策建议模板**

> （一）推动专门立法，健全制度体系。  
> （二）梳理现有规范，系统摸清底数。  
> （三）出台专项规范，统一引用规则。  
> （四）对接国际规则，开展先行先试。

**常见误区**

- 不要只有国外经验，没有我国问题。
- 建议要有制度层级，不能停留在“加强研究、加强交流”。

## 卡片7：数据信息

**适用场景**

- 拥有自建数据库、清单、监测数据、统计分析结果。
- 数据能说明趋势、结构、分布和监管启示。
- 适合科信司、技术创新中心、数字化监管、标准化、AI治理等主题。

**标题公式**

- `从某类数据/发布动向 + 预示我国某治理/监管方向`
- `某领域数据密集发布/快速增长 + 为某监管任务筑牢规则根基`
- `全球/全国某数据变化 + 显示某趋势`

**正文骨架**

1. 报送单位 + 信息类型：如“国家市场监督管理总局技术创新中心……报送数据信息”。
2. 数据来源和口径：说明数据库、样本范围、截至时间、收录数量。
3. 特点1：时间趋势，说明增速、占比、阶段判断。
4. 特点2：主体分布，说明组织、地区、行业、机构分布。
5. 特点3：类型结构，说明基础类、技术类、应用类、安全治理类等。
6. 总结判断：从数据中抽象出治理格局或监管方向。
7. 下一步：写本单位将如何深化研究、建设平台、开发智能体、服务监管现代化。

**语言风格**

- 数据先行，判断跟随数据。
- 每个分论点都要有数字、占比或排序。
- 适合配图表，如趋势图、组织分布图、领域分布图。

**对策建议模板**

> 下一步，〔报送单位〕将重点从两方面发力：一是深化智库研究，开展……；二是加快构建……，打造……，以……支撑……

**常见误区**

- 不要把数据信息写成普通观点稿；没有数据来源、口径和比例就不成立。
- 图表不能只是装饰，正文必须解释图表背后的趋势和监管含义。
- “下一步”要落到报送单位能力建设，不宜泛泛提国家层面对策。

## 卡片8：正面信息：部署类

**适用场景**

- 某项政策、文件、专项行动已经审议审签，即将正式发布或部署。
- 信息报送时间应早于公开发布、新闻发布。
- 篇幅约600字。

**标题公式**

- `市场监管总局/多部门 + 部署 + 某项工作`
- `市场监管总局等部门 + 启动/推进 + 某工程/行动`

**正文骨架**

1. 帽段：依据哪项中央部署，近日将开展什么工作，目标是什么。
2. 一是……：重点领域1。
3. 二是……：重点领域2。
4. 三是……：重点领域3。
5. 四是……：重点领域4，可选。

**语言风格**

- 简洁、确定、行动导向。
- 少写组织领导、宣传引导、保障措施。
- 不写尚未确定、仍在征求意见的事项。

**常见误区**

- 报送过晚会变成新闻稿。
- 报送过早则可能因政策未定而失真。

## 卡片9：正面信息：总结类/案例示范类

**适用场景**

- 总局或地方已推进某项工作并取得阶段性成效。
- 可用于总结经验、展示进展、形成示范。
- 篇幅约600字；案例示范可视材料适度展开。

**标题公式**

- `某项工作 + 取得积极进展`
- `某项工作 + 扎实推进`
- `某部门/地方 + 以某方式 + 推动某成效`

**正文骨架**

1. 帽段：中央部署/政策依据 + 已开展工作 + 总体成效。
2. 一是……：制度/政策协同。
3. 二是……：标准/平台/机制建设。
4. 三是……：重点领域推进。
5. 四是……：宣传推广、保护力度或国际合作，可选。
6. 结尾：当前仍存在短板 + 下一步工作。

**语言风格**

- 正向、凝练、面上概括。
- 主要写“做了什么、取得什么成效、下一步怎么干”。
- 一般不举太多地方小例子；如写案例示范，应把地方经验抽象为机制。

**结尾模板**

> 当前，……仍存在……等短板。下一步，市场监管总局将……，更好助力……

**常见误区**

- 不要写成宣传材料，必须有政策含量和可上报价值。
- 不要只罗列活动，要提炼机制和成效。

## 卡片10：基层反映

**适用场景**

- 地方市场监管部门发现的问题、风险、涉外动向、企业诉求。
- 可采编问题信息和涉外信息，体例参照“上报信息”。

**标题公式**

- `建议 + 深化/完善/强化 + 某合作/机制/监管 + 提升某能力`
- `某领域/某国家规则 + 面临机遇与挑战`
- `我国某类企业/产业 + 现状、问题及对策建议`

**正文骨架**

1. 帽段：引用中央领导讲话、重大会议或地方掌握的一线情况，说明上报价值。
2. 成效/现状：如已有机制、平台、合作基础，可先写成效。
3. 问题/挑战：列出3条左右，强调基层掌握的一线情况。
4. 对策建议：强调可落地、可由总局或相关部门推动的措施。

**语言风格**

- 比上报信息更突出一线观察和地方平台载体。
- 仍要保持国家视角，不能写成地方工作汇报。
- 可在建议中体现地方平台、研究中心、创新基地等承接能力。

**常见误区**

- 不要只讲地方成绩，要把地方经验升格为全国可参考的治理建议。
- 不要把“基层反映”理解为低层级材料，上报“两办”时体例和要求并无实质降低。

## 类型选择速查

按用户给定材料的特征匹配优先类型：

- **国外最新法规 / 标准 / 认证 / 贸易壁垒** → 涉外信息 · 国外动向类
- **国外成熟制度经验，可供我国借鉴** → 涉外信息 · 国际经验类
- **清单、数据库、统计结果、图表** → 数据信息
- **具体风险、堵点、企业困难、监管短板** → 问题信息
- **即将出台政策、专项行动、重要部署** → 正面信息 · 部署类
- **工作成效、阶段性进展、示范经验** → 正面信息 · 总结类 / 案例示范类
- **地方一线、企业诉求或地方平台观察** → 基层反映
